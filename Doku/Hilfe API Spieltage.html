⚽ Spieltage API

Liga-Management System - REST API Dokumentation

Base URL: /api/spieltage
ℹ️ Über diese API: Diese API verwaltet Spieltage für ein Liga-Management-System. Sie unterstützt unterschiedliche Liga-Typen (Liga 1, 2 und 3) mit spezifischen Operationen.
GET /api/spieltage/GetSpieltage ▶
Ruft alle Spieltage ab (AsNoTracking für bessere Performance)
📝 Beschreibung

Gibt eine Liste aller Spieltage zurück. Die Abfrage nutzt AsNoTracking für optimierte Performance bei Leseoperationen.

📤 Response

200 OK Liste der Spieltage erfolgreich abgerufen

500 Interner Serverfehler beim Datenbankzugriff

// Beispiel Response [ { "spieltagId": 1, "ligaID": 1, "nummer": 1, "datum": "2024-10-20T15:30:00" }, ... ]
GET /api/spieltage/GetSpieltageCount ▶
Gibt die Anzahl aller Spieltage zurück
📝 Beschreibung

Liefert die Gesamtanzahl der Spieltage in der Datenbank.

📤 Response

200 OK Anzahl erfolgreich abgerufen

500 Interner Serverfehler

// Beispiel Response 42
GET /api/spieltage/{id} ▶
Ruft einen spezifischen Spieltag anhand der ID ab
🔗 Parameter
Name Typ Position Beschreibung
id int Path Die eindeutige ID des Spieltags
📤 Response

200 OK Spieltag gefunden und zurückgegeben

500 Datenbankfehler

// Beispiel Response { "spieltagId": 5, "ligaID": 1, "nummer": 5, "datum": "2024-11-03T15:30:00", "spieleList": [...] }
💡 Beispiel Request
GET /api/spieltage/5
POST /api/spieltage ▶
Erstellt einen neuen Spieltag (unterschiedliche Logik für Liga 3)
📝 Beschreibung

Erstellt einen neuen Spieltag. Wichtig: Für LigaID < 3 wird AddSpieltag() verwendet, für LigaID >= 3 wird AddSpieltagL3() verwendet.

📥 Request Body
{ "ligaID": 1, "nummer": 10, "datum": "2024-12-15T15:30:00", "bemerkung": "Wichtiges Spiel" }
📤 Response

201 Created Spieltag erfolgreich erstellt

400 Ungültige Daten (Body ist null)

500 Fehler bei der Neuanlage

// Response Header Location: /api/spieltage/15 // Response Body { "spieltagId": 15, "ligaID": 1, "nummer": 10, "datum": "2024-12-15T15:30:00" }
PUT /api/spieltage ▶
Aktualisiert einen bestehenden Spieltag
📝 Beschreibung

Aktualisiert die Daten eines vorhandenen Spieltags. Die SpieltagId muss im Body enthalten sein.

📥 Request Body
{ "spieltagId": 15, "ligaID": 1, "nummer": 10, "datum": "2024-12-16T18:00:00", "bemerkung": "Geändertes Datum" }
📤 Response

200 OK Spieltag erfolgreich aktualisiert

400 Ungültige Daten

500 Fehler beim Update

DELETE /api/spieltage/{id}/{liganummer} ▶
Löscht einen Spieltag (spezielle Logik für Liga 3)
📝 Beschreibung

Löscht einen Spieltag. Wichtig: Für Liga 3 (liganummer = 3) wird DeleteSpieltagL3() verwendet, sonst DeleteSpieltag().

🔗 Parameter
Name Typ Position Beschreibung
id int Path Die ID des zu löschenden Spieltags
liganummer int Path Die Liganummer (3 für Liga 3, andere Werte für andere Ligen)
📤 Response

200 OK Spieltag erfolgreich gelöscht

500 Fehler beim Löschen

💡 Beispiel Request
DELETE /api/spieltage/15/3 // Liga 3 DELETE /api/spieltage/20/1 // Liga 1
🔐 Hinweise:
• Alle Endpunkte nutzen Try-Catch für Error-Handling
• Logging erfolgt über ILogger
• GET-Operationen verwenden AsNoTracking für bessere Performance
• Liga 3 hat spezielle Logik bei Create und Delete
